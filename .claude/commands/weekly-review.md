# Write the Monday resourcing meeting

Read CLAUDE.md. Fetch current records before answering. Run:

```bash
npm run plan -- weekly-review
```

All examples with angle brackets require a real value. Add --json for structured output. Names match without case sensitivity, or use an unambiguous id prefix. If matching is ambiguous, show candidates and ask the operator to choose. Never invent facts, hours or decisions. Run capacity, requests and attention separately too. Summarise the next four weeks, daily conflicts, uncovered roles and the named owners who need to act. Distinguish tentative work from commitments. Do not book people without an agreed decision.

Mutations require --actor and support --dry-run. Actor is attribution, not a verified identity. Drafts stay local. Nothing sends.
